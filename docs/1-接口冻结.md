## 1. 已有接口 · 冻结清单

### 1.1 HTTP 接口

| # | 服务 | 方法 | 路径 | 鉴权 | 返回 |
|---|------|------|------|------|------|
| 1 | agent-lite :8000 | `POST` | `/chat` | ✅ Bearer | `ChatResponse` |
| 2 | agent-lite :8000 | `POST` | `/chat/stream` | ✅ Bearer | SSE 流 |
| 3 | agent-lite :8000 | `GET` | `/sessions` | ✅ Bearer | `{count, sessions[]}` |
| 4 | agent-lite :8000 | `DELETE` | `/sessions/{session_id}` | ✅ Bearer | `{status, remaining}` |
| 5 | agent-lite :8000 | `GET` | `/health` | ❌ 无 | `{status, version}` |
| 6 | agent-lite :8000 | `GET` | `/` | ❌ 无 | `static/index.html` |
| 7 | agent-lite :8000 | `GET` | `/docs` · `/openapi.json` | ❌ 无 | FastAPI 自带 |
| 8 | go-gateway :3000 | `GET` | `/health` | ❌ 无 | `{gateway, agent, agent_url}` |
| 9 | go-gateway :3000 | `*` | `/chat` `/sessions` `/docs/*` `/` | 透传 | 反向代理到 agent-lite |

**请求/响应体（字段名与类型冻结）**

```python
ChatRequest   { message: str, session_id: str | None, model: str | None }
# session_id 不传 → 后端自动分配
# model、api_key、base_url 为 2026-09-25 追加的可选字段。
# 三者属于同一条渠道：api_key 是供应商密钥，不是本服务的 API_KEY。都不传则仍用进程环境变量。
ChatResponse  { reply: str, status: "ok" | "error", error: str | None, session_id: str }
```

**冻结理由**：前端 `static/index.html`、Go 网关路由、CI 三者都依赖这套路径与字段。

### 1.2 SSE 事件协议 ★ 最高风险项

| `type` | 载荷字段 | 触发时机 |
|--------|----------|----------|
| `session` | `session_id` | 流的**第一条事件**，固定 |
| `delta` | `content` | 每个文本片段 |
| `tool_call` | `name`, `args` | 模型发起工具调用 |
| `done` | `reply` | **正常终止事件** |
| `error` | `message` | 异常终止 |
| `usage` | `prompt_tokens`, `completion_tokens` | 每一轮模型调用结束后的累计消耗。2026-09-25 新增，旧前端应忽略 |

**冻结理由**：前端逐条解析这五种事件。**改动任一 `type` 名或字段名 = 前端必须同步重写。**

> v2 若要新增可观测事件（如 `span`），**只能新增 `type`，不得修改既有五个**。前端遇到未知 `type` 应忽略而非报错 —— 这一条在 v2 前端改造时要一并确认。

### 1.4 工具名（模型调用契约）

| 工具名 | 类型 | 能力 |
|--------|------|------|
| `calculate` | 本地 | 表达式求值（白名单 AST 求值，非 `eval`） |
| `read_file` | 本地 | 读文件 / 列目录（限制在项目目录内） |
| `get_time` | 本地 | 当前日期时间 |
| `weather` | 远程 MCP | 天气查询 |
| （动态） | 远程 MCP | 名称由 `setup_mcp_connections()` 发现 |

**冻结理由**：工具名是**模型按名调用**的契约。改名 → 提示词失效 → 所有历史会话的工具调用记录失去参照。

**规则**：
- ✅ **允许**：新增工具
- ⚠️ **需评估**：给已有工具加参数（旧调用不带新参数时必须有合理默认）
- ❌ **禁止**：重命名或删除已有工具

> 🔴 **v1 已知问题**：`SYSTEM_PROMPT` 里只列了 3 个工具（`calculate` / `read_file` / `get_time`），**实际可用 5 个**（含 `weather` 和 MCP 远程工具）。模型不知道有天气工具。→ v2 修正。

### 1.5 RAG / 记忆接口 ★ v1 最值钱的资产

```
RAGStore(session_id: str = "default")
  ├─ collection    : "agent_memory"                     ← 改名 = 旧数据全丢
  ├─ 隔离方式      : metadatas=[{"session_id": ...}] + query(where={...})
  ├─ add(text)     : 写入，id = uuid4().hex
  ├─ search(q, k)  : 语义检索，仅本 session
  ├─ restore()     : 按 session_id 恢复历史摘要
  ├─ count()       : 按 session_id 计数
  └─ embedding     : 本地 BAAI/bge-small-zh-v1.5（fastembed，512 维）
                     cache_dir = agent-lite/models/

HybridMemory(system_prompt, client, session_id="default",
             summary_trigger=15, keep_recent=6)
  ├─ short_term : list[dict]
  ├─ long_term  : list[{summary, timestamp}]
  ├─ build_context()      : system + RAG 检索结果 + short_term
  └─ maybe_summarize()    : 超阈值 → 模型摘要 → 转长期 + 入 ChromaDB
```

**冻结理由**：`collection` 名与隔离机制一旦变更，**v1 已落库的向量数据将无法读取**。

> **这个设计必须原样保留到 v2**：全局单例 + 线程锁懒加载 embedding 模型（避免每个 session 重复加载 ~100MB），是本项目最扎实的一处工程决策。

## 5. 本清单的使用规则

1. **动手改任何接口前先查这份文档**。不在冻结清单里的 → 可以自由设计；在清单里的 → 必须走 `第 3 节 变更记录`。
2. **测试优先于文档**：如果代码与本文档冲突，**以代码为准**，并立即回来更新本文档。
3. **不写进文档的接口 = 不存在**：v2 新增的每一个对外契约，必须补进第 2 节。
